# BEP---Simulating-Echo-Planar-Imaging-and-associated-artifacts-for-an-Educational-MRI-simulator
This repository contains the file that, written in python, is the code to acquire an MRI image with Echo Planar Imaging. This is applied into EduMRIsim, an educational MRI simulator created by Stephanie Gonzalez, a Phd student at the TU/e.
